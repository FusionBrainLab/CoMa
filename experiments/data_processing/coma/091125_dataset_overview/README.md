# Dataset Analysis and Visualization

## Overview
Generates comprehensive dataset statistics and creates visualizations of massings within their surrounding context.

## Operations Performed
- **Dataset statistics analysis**: Creates distribution plots for key dataset attributes
- **Massing context visualization**: Generates images showing massings within their environmental context

## Input Data
- `dataset.json` from `data_processing/271025_final_data_processing`

## Output
- Statistical plots saved in subfolder
- Context visualization images saved in subfolder

## Execution
```bash
python main.py
```
