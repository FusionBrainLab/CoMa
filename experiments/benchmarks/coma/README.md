Хотим проверить, как зависит качество генерации массингов через влм в соответствии с контекстом от форматов подачи контекста на обучении и инференсе.
Массинг представляется в виде json, контекст это набор массингов.
Под форматом подачи контекста подразумевается то, в какой вид мы преобразовываем контекст перед подачей его в влм.
Зафиксируем, что такое соответствие контексту абстрактно.
Соответствовать контексту - значит вести себя так же, как реальные здания ведут себя в реальном контексте. То есть "здание соответствует контексту" = "здание ведет себя так же, как реальное здание в этом контексте". При этом мы подразумеваем, что геометрия здания неким образом зависит от контекста, иначе такой замер соответствия не имел бы смысла.
Зафиксируем, что значит соответствие контексту на практике.
Мы не знаем наверняка, каким образом геометрия массинга зависит от контекста. Однако метрика оценки контекста по сути является бинарным классификатором - является ли массинг истинным для этого контекста или нет. И ее можно развернуть в обратную сторону - проверять, является ли контекст истинным для массинга. Соответственно, если метрика будет чувствительна к изменению контекста, значит она кодирует верную зависимость массинга от контекста и ее можно использовать.

Все метрики вычисляются по такой схеме:
Е = exp(-|gen_massing_value - reduction(context_values)| / (context_values_std + small_constant))
reduction = mean, nearest (берем ближайшее значение к get_massing_value)

Оценивать метрики будем методами оценки бинарной классификации: ROC-AUC, Recall@k, F1-Score. При этом датасет для оценки метрики будет строиться следующим образом - берем весь датасет CoMa, для каждого сэмпла делаем негативный пример, случайным образом подмешивая туда чужой контекст, получаем тем самым удвоенный датасет с одинаковым количеством positive и negative сэмплов.






Зафиксируем, что значит соответстие контексту на практике.
Очевидно, что соответствие следует измерять, если массинг действительно зависит от контекста. Для конкретизации примем, что зависимость выражается в зависимости неких параметров массинга от неких парамеров контекста. Соответственно, оценка соответствия массинга контексту вырождается в набор метрик, каждая из которых оценивает соответствия массинга контексту с точки зрения определенной характеристики. При этом наши метрики должны быть такими, что:
- массинг и контекст должны коррелировать по оцениваемым параметрам - то есть метрика должна оценивать массинг по параметру, который действительно важен при учете контекста
- метрика должна быть чувствительна к изменению контекста с точки зрения оцениваемого параметра контекста и быть хорошей для истинной пары массинг-контекст - то есть значение метрики для истинной пары должно быть около идеального и уменьшаться при подмене контекста на более удаленный по конкретному параметру
- на примере сгенерированных массингов с разными значениями метрики должно быть визуально видно их разное соответствие контексту
Для оценки по каждой метрике надо отобрать валидационный сет с наиболее разнообразными контекстами, причем для каждой метрики контекст будет разнообразен по своему.

Зафиксируем, что такое соответствие контексту на практике.
Допустим, что массинг зависит от контекста, если некая характеристика массинга зависит от некой характеристики контекста. Тогда метрик соответствия контексту может быть много, и каждая из них должна измерять валидность значения характеристики массинга при условии значения характеристики контекста. Тогда введем следующую формализацию.
Пусть у массинга есть некий характеристический объект и у контекста есть некий характеристический объект, у этих объектов есть некие численные характеристики (в частном случае характеристические объекты сами являются числами). Пусть численные характеристики этих объектов скоррелированы, то есть некая характеристика массинга зависит от некоторой характеристики контекста. Пусть определена функция сравнения этих характеристик, при этом эта функция чувствительна к изменению контекста - чем дальше контекст от истинного по его характеристике, тем значение функции меньше. Тогда соответствие массинга контексту определяется значением этой функции.

Пусть у массинга есть некий характеристический объект и у контекста есть объект аналогичной природы. У этих объектов есть некие численные характеристики. При этом эти характеристики скоррелированы (между ними есть биективная зависимость). Над этими объектами определена функция, которая показывает значение около идеального на реальных парах массинг-контекст и ее значение уменьшается при изменении контекста на наиболее далекий по численным характеристикам. Тогда массинг соответствует контексту, если эта метрика показывает высокое значение.
